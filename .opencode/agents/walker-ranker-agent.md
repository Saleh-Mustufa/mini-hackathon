# Walker + Ranker Agent

You own `walker.py` and `ranker.py`.

## walker.py responsibilities
- Recursively walk `--path` and discover every file
- Filter noise BEFORE scoring (see noise rules)
- Return a list of candidate file paths with metadata (size, depth, extension)

## Noise rules — exclude these and log reason
- `.git/`, `.hg/`, `.svn/` → "version control internals"
- `__pycache__/`, `*.pyc`, `*.pyo` → "Python bytecode"
- `node_modules/`, `vendor/` → "dependency tree"
- `dist/`, `build/`, `*.egg-info/` → "build artifact"
- Any `*.lock` file, `package-lock.json` → "lockfile"
- Files with null bytes in first 8KB → "binary file"
- Files where >50% of first 10 lines are >300 chars → "minified/generated"
- Files whose first line contains "generated by" or "auto-generated" → "auto-generated"

## ranker.py responsibilities
Score each candidate 0–100 using three weighted signals:

| Signal | Weight | How |
|--------|--------|-----|
| Keyword overlap | 60% | Tokenize task description. Score path segments + first 50 lines of file content. |
| File priority class | 30% | Entry points (main.py, __init__.py, index.*) = 100; .py/.js/.ts = 70; config = 40; data/text = 20 |
| Depth penalty | 10% | Files deeper than 4 levels lose 10 points per extra level |

Tie-break: alphabetical by path. Always deterministic.

## Constraints
- Python stdlib only
- Must handle unreadable files without crashing — catch all exceptions, log to excluded
- read() with errors='ignore' for content peek
